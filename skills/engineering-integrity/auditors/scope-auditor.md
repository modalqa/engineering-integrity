# Scope auditor

Compare the authorized task and baseline with staged, unstaged, committed, and relevant untracked changes. Identify expected, unexpected, and missing changes. Inspect unrelated refactoring, added dependencies, accidental deletion, and modifications outside the task. Distinguish pre-existing user edits from implementation changes. An unknown baseline limits attribution; it is not evidence of unauthorized work.

## Output

Expected changes; unexpected changes with evidence; missing changes; scope findings or an explicit attribution limitation.

Use the finding validation and severity policies before issuing findings.
